# 아르데르 카드 챗 RPG · 서비스 설계 v2

## 제품 한 문장

캐릭터 챗처럼 인물과 관계를 쌓되, 플레이어의 행동은 자연어 입력이 아니라 현재 상황에 맞는 카드로 선택하는 지속형 판타지 RPG.

## 이번 세로 슬라이스

첫 캠페인 「잿빛 서약」은 솔라니아 제국 서문에서 태양교단 조사관 세라 아벨린을 만나는 것으로 시작한다. 플레이어는 월식 파편 탈취 사건을 조사하고, 세라와 서약 또는 계약을 맺은 뒤 거점에서 관계·의뢰·여행·핵심 사건을 자유롭게 오간다.

캠페인은 날짜 만료로 끝나지 않는다. 사망이나 명시적인 서사 엔딩만 종료 조건이 되며, 현재 세로 슬라이스는 제2장 거점 루프까지 열린 상태다.

## 플레이 루프

1. 서버가 저장된 상태와 현재 장면을 읽는다.
2. 코드가 조건에 맞는 카드와 잠금 상태를 확정한다.
3. 플레이어가 카드 한 장을 선택한다.
4. 코드가 수치·아이템·관계·플래그·기억을 원자적으로 반영한다.
5. 다음 장면과 최근 대화, 회고 요약을 저장한다.
6. 설정된 경우에만 AI가 확정된 장면 묘사와 대사를 변주한다.

## 기억 설계

| 층 | 저장 내용 | 쓰임 |
|---|---|---|
| 확정 상태 | 수치, 아이템, 직업, 플래그, 관계 | 카드 조건과 결과 판정의 근거 |
| 사건 기억 | 약속, 비밀, 거래, 구조, 서약, 발견 | 관계 대사, 회고, 장기 분기 |
| 최근 대화 | 서술자·NPC·플레이어·시스템 메시지 | 채팅형 화면과 단기 맥락 |
| 회고 | 중요도 높은 기억의 요약 | 재접속 시 빠른 복귀와 AI 문맥 |

기억은 자연어 전문만 쌓지 않고 `type`, `subject`, `importance`, `tags`, `turn`을 함께 저장한다. 따라서 “세라와 관련된 중요 비밀”, “구조한 사건”, “악마숭배자와의 거래”처럼 코드가 안정적으로 검색할 수 있다.

## AI 경계

AI가 맡을 수 있는 일:

- 현재 장면 묘사와 NPC 대사의 자연스러운 변주
- 확정된 성격, 관계, 기억을 반영한 말투 조절

AI가 맡지 않는 일:

- 카드 목록과 잠금 조건 결정
- 성공·실패와 수치 계산
- 아이템·직업·플래그 부여
- 장기 기억의 생성 여부와 중요도 결정
- 공식 세계관 밖 국가·신격·마계 위계 생성

이 경계 덕분에 모델 변경이나 장애가 게임 규칙을 망가뜨리지 않는다.

## 저장과 접근

- 캠페인 전체를 버전이 있는 JSON 스냅샷으로 저장한다.
- 로컬은 H2, 배포는 PostgreSQL을 사용한다.
- 생성 시 256비트 게스트 토큰을 한 번 발급하고 DB에는 해시만 저장한다.
- 버전 조건부 갱신과 `requestId` 기록으로 동시 선택 및 모바일 재전송을 방어한다.
- 웹 클라이언트는 캠페인 ID와 토큰을 브라우저에 보관해 이어하기를 제공한다.

## 서비스 확장 순서

### 1. 콘텐츠 확장

- 제2장 핵심 사건의 결말과 제3장 국가별 분기
- 세라 외 동료 2명과 인물별 기억/관계 이벤트
- 같은 장면의 반복을 줄이는 쿨다운과 사건 덱
- 운영자가 JSON/YAML로 장면·카드·조건을 편집하는 콘텐츠 도구

### 2. 계정과 동기화

- 이메일/소셜 로그인과 게스트 캠페인 귀속
- 사용자당 여러 캠페인 슬롯
- 기기 간 동기화, 토큰 회수, 계정 삭제

### 3. 운영 안정성

- Flyway 스키마 마이그레이션
- 요청 제한, 감사 로그, 오류/지연 지표
- AI 호출 큐·회로 차단기·비용 한도
- 스냅샷 백업과 복구 훈련

### 4. 수익화 검증

- 본편 진행을 막지 않는 외형·추가 캠페인 중심 상품
- 결제와 별개로 기억/세이브의 영속성을 보장
- 선택 결과를 바꾸는 확률형 판매는 배제

## 현재 범위 밖

이번 버전은 플레이 가능한 서비스 코어이지, 공개 출시의 모든 운영 기능을 끝낸 버전은 아니다. 계정 로그인, 결제, 관리자 도구, 다중 인스턴스 분산 잠금, 신고/차단, 운영 대시보드는 다음 단계에 속한다.
